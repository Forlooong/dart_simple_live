更新概要
• 恢复抖音直播间弹幕，修复 Windows 调整窗口大小后内容区变灰的问题。

更新详情

抖音弹幕
• 弹幕连接与播放请求独立运行，切换画质等操作取消播放请求时，聊天仍可继续。
• 连接失败或断开时，重新获取当前直播间的访客会话，并限制连续重试次数。
• 主应用关闭播放器滚动弹幕后，直播间聊天列表仍接收新消息。再次开启后，新消息继续滚动显示。

Windows 窗口
• 更新 Windows 渲染引擎，修复连续缩放、最大化还原及最小化还原时可能出现的灰屏。
• 首页已在 100%、125% 和 150% 显示缩放下验证。公开直播间在 150% 下验证了缩放后的视频播放和弹幕更新。
